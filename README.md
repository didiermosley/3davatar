# 3D Avatar Creator

Avatar creator for men and women with customizable hair, facial hair, outfits, shoes and colors. Built with Next.js, Three.js (React Three Fiber) and zustand.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Features

- Gender: man / woman with different body proportions
- Men: mustache, beard, haircut, t-shirt, pants
- Women: hair style, t-shirt, pants, skirt, dress
- Both: skin color, hair color, eye color, expression, shoe style and color
- Extras: glasses, sunglasses, cap, beanie, hat, background color
- Randomize, reset, auto-rotate, share link, PNG export
